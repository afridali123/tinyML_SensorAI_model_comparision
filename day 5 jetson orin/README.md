# Day 5 Jetson Orin Nano Deployment

This folder shows how to take the Keras models from the Day 5 image notebooks, export them to ONNX on the host PC, build TensorRT engines on Jetson Orin Nano, and run inference with Python.

Supported models:

- Notebook 09 Fashion-MNIST CNN
- Notebook 10 Cats-vs-Dogs transfer-learning model

## Folder Layout

```text
day 5 jetson orin/
  README.md
  requirements-host.txt
  notebooks/
    01_keras_to_onnx_tensorrt_jetson_orin.ipynb
  host/
    export_models_to_onnx.py
  jetson/
    build_tensorrt_engines.sh
    infer_jetson_orin.py
  bundle/                # generated by host export script
  engines/               # generated on Jetson by build script
```

## What Runs Where

Run on the host PC:

```text
Keras model -> ONNX model -> bundle folder
```

Run on Jetson Orin Nano:

```text
ONNX model -> TensorRT engine -> live/sample inference
```

TensorRT engines should be built on the target Jetson device because engines are tied to TensorRT version, CUDA version, GPU architecture, and precision settings.

## Step 1: Make Sure Keras Models Exist

Notebook 10 already saves:

```text
models/keras/notebook10_cats_dogs_transfer.keras
```

Notebook 09 may not save its model in older copies. The host export script can train and save the Fashion-MNIST model if it is missing.

## Step 2: Export ONNX Bundle On Host PC

From the main course workspace root:

```powershell
python "day 5 jetson orin/host/export_models_to_onnx.py" --train-missing-fashion
```

This creates:

```text
day 5 jetson orin/bundle/fashion_mnist_cnn.onnx
day 5 jetson orin/bundle/fashion_mnist_cnn.json
day 5 jetson orin/bundle/fashion_mnist_sample.npy
day 5 jetson orin/bundle/cats_dogs_transfer.onnx
day 5 jetson orin/bundle/cats_dogs_transfer.json
day 5 jetson orin/bundle/cats_dogs_sample.npy
```

## Step 3: Copy Folder To Jetson Orin Nano

Copy this folder to the Jetson, for example:

```bash
scp -r "day 5 jetson orin" jetson@<JETSON_IP>:~/edge_ai/
```

## Step 4: Build TensorRT Engines On Jetson

On Jetson:

```bash
cd ~/edge_ai/day\ 5\ jetson\ orin
chmod +x jetson/build_tensorrt_engines.sh
./jetson/build_tensorrt_engines.sh --precision fp16
```

This creates:

```text
engines/fashion_mnist_cnn_fp16.engine
engines/cats_dogs_transfer_fp16.engine
```

Use `--precision fp32` if FP16 is not wanted.

## Step 5: Run Inference On Jetson

Fashion-MNIST sample inference:

```bash
python3 jetson/infer_jetson_orin.py --model fashion --precision fp16
```

Cats-vs-Dogs sample inference:

```bash
python3 jetson/infer_jetson_orin.py --model catsdogs --precision fp16
```

Run with your own image:

```bash
python3 jetson/infer_jetson_orin.py --model catsdogs --image /path/to/cat_or_dog.jpg --precision fp16
```

## Jetson Dependencies

On Jetson Orin Nano with JetPack installed, TensorRT is normally already available. You may need:

```bash
sudo apt-get update
sudo apt-get install -y python3-pip python3-opencv
python3 -m pip install numpy pillow pycuda
```

Verify TensorRT:

```bash
python3 -c "import tensorrt as trt; print(trt.__version__)"
trtexec --version
```
